# Jaemin Cho · Game Developer Portfolio

Portfolio for GitHub Pages: **https://shinmango99.github.io/Portfolio/**

```
index.html       Home: pitch, proof, featured games, category portal, contact
solo.html        Solo Projects      (category pages share one renderer)
team.html        Team Projects
teaching.html    Teaching
project.html     one page per project: project.html?id=<project id>
about.html       bio, resume, abilities, timeline
contact.html     contact details
css/style.css    styles (colours/fonts are the variables at the top)
js/data.js       ALL content: profile, reel, categories, skills, milestones, projects
js/main.js       rendering only (<body data-page> picks the page)
assets/          images, videos, icons
```

Master reel: set `profile.reel` in `js/data.js` to a YouTube URL or `assets/video/reel.mp4`.
